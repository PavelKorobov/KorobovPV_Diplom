## Создание профилей групп доступа»

Создайте профили групп доступа «Бухгалтер ИТ фирмы», «Менеджер», «Специалист», «Кадровик-расчетчик». Настройте роли добавленным профилям:

### Бухгалтер ИТ фирмы

- Базовая функциональность ТП
- Базовые права БСП
- Запуск веб-клиента
- Запуск тонкого клиента
- Использование универсального отчета
- Массовое создание документов продажи
- Сохранение данных пользователя

### Менеджер:

- Базовая функциональность ТП
- Базовые права БСП
- Добавление изменение документов обслуживания клиентов
- Добавление изменение контрагентов
- Запуск веб-клиента
- Запуск тонкого клиента
- Использование универсального отчета
- Сохранение данных пользователя

### Специалист:

- Базовая функциональность ТП
- Базовые права БСП
- Запуск веб-клиента
- Запуск тонкого клиента
- Использование универсального отчета
- Сохранение данных пользователя
- Чтение изменение документов обслуживания клиентов

### Кадровик-расчетчик:

- Базовая функциональность ТП
- Базовые права БСП
- Запуск веб-клиента
- Запуск тонкого клиента
- Использование универсального отчета
- Расчет управленческой зарплаты
- Сохранение данных пользователя

 Назначьте пользователям, соответствующие их должностям, профили групп доступа. 

#### Бухгалтер ИТ фирмы. 
Имеет доступ к массовому созданию документов продажи и отчету по анализу выставленных актов. Имеет возможность настроить значения констант «Номенклатура работы специалиста» и «Номенклатура абонентская плата».

#### Менеджер 
Имеет возможность создавать документ «Обслуживание клиента», редактировать шапку документа и записывать документ. Также имеет возможность добавлять новых контрагентов и редактировать значения констант «Токен управления Телеграмм ботом» и «Идентификатор группы для оповещения».

#### Специалист 
Имеет возможность редактировать табличную часть документа «Обслуживание клиента» и проводить документ. Также может просматривать отчет по выработке специалистов.

#### Кадровик-расчетчик
Может создавать и редактировать все документы, связанные с начислением и выплатой зарплаты. Имеет возможность настроить условия оплаты сотрудников, график отпусков, графики работы. Имеет доступ к отчетам о выработке специалистов, расходе запланированных отпусков, расчетах с сотрудниками. Также может установить значение НДФЛ.

## Отправка уведомлений в группу Телеграмм

### Создание бота

Напишите в строке поиска Телеграмм «BotFather» и перейдите в найденный чат. В строке чата введите команду /start. В тексте ответа чата выберите команду /newbot и введите название бота (name), которое будут видеть пользователи. Затем введите идентификатор бота (username), он должен заканчиваться на 'bot' (Пример: «Service_bot»). Далее чат сообщит о том, что бот создан и предоставит токен доступа к боту (пример токена: 8529487967:AAFw0cHDBf-D8JvVzwz4BWllICUlBgEAaVM). Сохраните токен.

### Создание группы

Создайте группу в Телеграмм. Добавьте созданного бота в группу и назначьте ему права администратора.

### Идентификатор группы

Напишите любое сообщение в созданную группу. С помощью программы Postman выполните запрос https://api.telegram.org/bot[ВашТокен]/getUpdates. Переключите отображение ответа в вид JSON. Идентификатор группы находится внутри объекта «chat» в поле «id» (Пример идентификатора: -5110323679). Либо узнайте идентификатор группы Телеграмм любым известным вам способом. Сохраните идентификатор группы.

### Настройка констант

Требуется установить значения констант «Токен управления Телеграмм-ботом» и «Идентификатор группы для оповещения». Это может сделать либо пользователь с правами администратора, либо пользователь, которому назначен профиль групп доступа «Менеджер». Для этого на начальной странице в панели разделов нажмите «Обслуживание клиентов». В подменю «Сервис» нажмите «Токен управления Телеграмм-ботом» или «Идентификатор группы для оповещения» и установите ранее сохраненное соответствующее значение токена доступа к боту и значение идентификатора группы.

### Отправка уведомлений

Для настройки отправки уведомлений по расписанию добавьте в «Дополнительные отчеты и обработки» обработку «ОтправкаУведомленийВГруппуТелеграмм». Настройте расписание для добавленной обработки.

## Константы с номенклатурой

Установите значения констант «Номенклатура работы специалиста» и «Номенклатура абонентская плата». Это может сделать либо пользователь с правами администратора, либо пользователь, которому назначен профиль групп доступа «Бухгалтер ИТ фирмы». Для этого на начальной странице в панели разделов нажмите «Обслуживание клиентов». В подменю «Сервис» нажмите «Номенклатура работы специалиста» или «Номенклатура абонентская плата» и установите значения, создав нужные элементы справочника «Номенклатура».

## Условия оплаты сотрудников

### Оклад и процент от работ

Необходимо указать размер окладов сотрудников, а также процент от работ специалистов. Это может сделать либо пользователь с правами администратора, либо пользователь, которому назначен профиль групп доступа «Кадровик-расчетчик».  Для этого на начальной странице в панели разделов нажмите «Управленческая зарплата». В подменю «См. также» нажмите «Условия оплаты сотрудников», добавьте записи в регистр. 

### График рабочих дней

Также следует заполнить регистр, отражающий наличие рабочих и не рабочих дней в выбранном периоде. Для этого в подменю «Сервис» нажмите «Заполнение графика». В открывшейся форме укажите необходимые данные для заполнения регистра. Выходные дни указываются как номера дней недели (например: 6,7).

### Размер НДФЛ

В этом же разделе в подменю «Сервис» необходимо нажать «Размер НДФЛ» и указать размер НДФЛ в процентах.
